# Artificial Intelligence and Neural Networks Lab Practicals

This repository contains Python implementations of various Artificial Intelligence and Neural Network algorithms using Python, TensorFlow, Keras, and PyTorch.

The practicals cover fundamental concepts of Artificial Neural Networks (ANN), Deep Learning, Pattern Recognition, and Machine Learning with graphical visualization and real-world applications.

---

# Technologies Used

- Python
- TensorFlow
- Keras
- PyTorch
- NumPy
- Matplotlib
- Scikit-learn

# List of Practicals

| Sr No | Practical Name | Description |
|------|----------------|-------------|
| 1 | Activation Functions Plotting | Plot different activation functions used in neural networks such as Sigmoid, ReLU, Tanh, and Softmax. |
| 2 | McCulloch-Pitts ANDNOT Function | Generate ANDNOT logical function using McCulloch-Pitts neural network model. |
| 3 | Perceptron for Even/Odd Recognition | Recognize even and odd ASCII numbers using Perceptron Neural Network. |
| 4 | Perceptron Learning Law | Demonstrate perceptron learning algorithm with decision boundary visualization. |
| 5 | Bidirectional Associative Memory (BAM) | Implement BAM using two pairs of input-output vectors. |
| 6 | ANN Training using Forward and Back Propagation | Implement neural network training process using forward and backward propagation algorithms. |
| 7 | XOR using Backpropagation Network | Solve XOR problem using Backpropagation Neural Network with binary inputs and outputs. |
| 8 | ART Neural Network | Illustrate Adaptive Resonance Theory (ART) neural network implementation. |
| 9 | Feed Forward Neural Network | Create a Backpropagation Feed Forward Neural Network in Python. |
| 10 | Hopfield Network | Design a Hopfield Network capable of storing four vectors. |
| 11 | TensorFlow/PyTorch Neural Network Training | Train neural networks and evaluate logistic regression using TensorFlow. |
| 12 | CNN Implementation | Implement Convolutional Neural Network (CNN) using TensorFlow/PyTorch. |
| 13 | MNIST Handwritten Digit Detection | Detect handwritten digits using TensorFlow, Keras, and PyTorch on MNIST dataset. |
